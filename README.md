# Frontend
React
Vite
Node.js
JavaScript / TypeScript
# Backend
Python
FastAPI
Uvicorn
# Installation
## Frontend
```bash
cd frontend
```
## Install dependencies:
```bash
npm install
```
## Run the server:
```bash
npm run dev
```
# Backend
## Open the new terminal and enter the backend folder:
```bash
cd backend
```
## Run FastAPI:
```bash
uvicorn main:app --reload
```
